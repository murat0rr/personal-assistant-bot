# Входящее — обратная связь, требующая решения

Этот файл строит и поддерживает **только периодический облачный
агент** (Phase 85, предложение: https://claude.ai/artifact/8xwZx1gqfuuM2KRKmSrNfA,
§1–§7) — перестраивает его из таблицы `feedback` в Postgres на каждом
прогоне. Ручные правки теряются при следующем прогоне.

Сюда попадает всё, что **не** auto_applicable — фичи, идеи,
пожелания по дизайну, и всё, на чём агент сам застопорился при
попытке автофикса (не прошло по allowlist, тесты не сошлись,
неоднозначно на месте). Сам агент это не трогает — читаешь и решаешь
в обычном чате со мной, когда удобно, тем же циклом, что остальные
фазы (см. `TECHDEBT.md` за похожим прецедентом — "бэклог, не в коде").
